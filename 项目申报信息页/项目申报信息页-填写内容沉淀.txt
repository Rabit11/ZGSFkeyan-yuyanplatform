一、页面结构总览
--------------------------------------------------------------------------------
1. 外层：项目申报列表页（查询、新建、材料清单、提交/审批/撤销/备案）
2. 内层抽屉标题：新建项目申报 / 编辑项目申报
3. 抽屉内区块标题：项目基本信息
4. 区块顺序：
   (A) 基础信息字段
   (B) 申报须填岗位（13 岗 · 姓名及工号）
   (C) 页底经费说明


二、基础信息字段（按界面顺序）
--------------------------------------------------------------------------------

1. 项目名称 *
   - 控件：单行文本输入
   - 占位提示：按立项文件全称填写
   - 附属操作：【项目查重】按钮（输入框右侧）
   - 查重规则：按名称与已有「申报单 / 项目」做包含匹配；
               有相似项提示「发现相似项目/申报 N 条」；无则提示可继续填报
   - 未填名称时点查重：提示「请先填写项目名称」

2. 项目渠道（来源） *          ← 现网补充（材料清单按渠道自适应）
   - 控件：下拉选择（可搜索）
   - 选项格式：[层级] 渠道名称，如 [国家级] MJKY、[公司级] 预研三年滚动计划
   - 作用：决定申报材料清单哪些字段开放/锁定；保存后列表展示渠道与项目层级

3. 是否需要审批 *
   - 控件：单选
   - 选项：
     a) 需审批（按渠道走线上审签）     ← 默认选中（needApproval = 1）
     b) 无需审批（直接线上报备）       （needApproval = 0）

4. 项目目标
   - 控件：多行文本（约 3 行）
   - 占位提示：项目整体目标...
   - 必填：否

5. 申请经费（万元）
   - 控件：数字输入（≥0，保留 2 位小数）
   - 必填：否
   - 备注：经费仅在此处填写一次（见页底说明）；立项备案时写入项目主表 totalFund

6. 开始时间
   - 控件：日期选择（YYYY-MM-DD）
   - 新建默认：2026-09-01
   - 必填：否

7. 结束时间
   - 控件：日期选择（YYYY-MM-DD）
   - 新建默认：2029-08-31
   - 必填：否

8. 参研单位
   - 控件：单行文本
   - 占位提示：如：北研中心、南京航空航天大学
   - 填写说明：多个单位以顿号/逗号分隔
   - 必填：否

9. 一级专业 *
   - 控件：下拉选择（可搜索）
   - 占位提示：请选择
   - 字典来源：附件1专业字典（frontend/src/config/major1-major2.json）
   - 取值格式：编码+名称，如 10-总体气动
   - 变更时：清空已选二级专业

10. 二级专业 *
    - 控件：下拉选择（可搜索）
    - 占位提示：未选一级时「请先选一级专业」；已选一级时「请选择」
    - 依赖：必须先选一级专业；下拉仅展示该一级下的二级项
    - 规则：二级编码前两位须严格等于一级编码（如 1001 → 10）

11. 管理/需求单位
    - 控件：单行文本
    - 占位提示：内部项目可与责任单位相同
    - 必填：否

12. 责任单位/牵头单位 *
    - 控件：下拉选择（可搜索）
    - 新建默认：中国商飞总部
    - 现网选项：
        中国商飞总部、上飞院、上飞公司、北研中心、客服公司、试飞中心
    - 落库：同步写入 orgName（列表「责任单位」列取 leadOrgName）

13. 牵头单位主要工作内容 *
    - 控件：多行文本（约 3 行）
    - 占位提示：牵头单位在本项目中的主要任务
    - 备案同步：写入项目主表 mainWork


三、一级 / 二级专业字典（附件1口径摘要）
--------------------------------------------------------------------------------
权威文件：major1-major2.json（源自《附件1.预先研究项目信息-表头-项目处.xlsx》）

一级专业（8 项）：
  10-总体气动
  20-机体
  30-系统
  40-制造
  50-复合材料
  60-飞行
  70-运行支持
  80-通用基础

二级专业示例（完整见 JSON）：
  10 → 1001-总体与气动 / 1002-需求与验证 / 1003-适航与四性 / 1004-舱室
  20 → 2001-材料与工艺 / 2002-强度 / 2003-结构
  30 → 3001-航电电气 / 3002-飞控 / … / 3006-环控与氧气
  …（其余见配置文件）

强制规则：
  1) 入库与展示须用完整 canonical 值（含编码前缀），勿只写中文简称
  2) 二级前两位 = 所属一级编码


四、申报填报岗位（姓名及工号）— 共 13 个必填岗位
--------------------------------------------------------------------------------

4.1 顶部提示条
--------------------------------------------------------------------------------
- 未选满：信息色提示「已选择 N/13 个申报岗位，成员库已覆盖全部岗位人选」
- 选满 13：成功色提示「候选人员已覆盖全部 13 个申报岗位，可完成项目全流程流转」
  （与截图绿条语义一致）

4.2 表头与布局
--------------------------------------------------------------------------------
表头两列：
  - 申报须填岗位
  - 姓名及工号
左侧分组列：项目团队 / 责任专家 / 管理团队 / 财务团队

4.3 人员选择统一交互
--------------------------------------------------------------------------------
- 控件：可搜索下拉（成员管理台账全量候选人）
- 占位模板：点击选择【岗位名称】，或输入姓名/工号搜索
- 全部标记为必填 *
- 搜索范围：姓名、工号、单位、部门、任职身份、项目岗位
- 下拉选项展示（两行）：
    主行：姓名（工号）          例：顾顺远（100013）
    副行：单位 / 部门 · 任职    例：上飞院 / 科研项目处 · 项目联系人
- 选中后输入框回显：仅「姓名（工号）」（option-label-prop）
- 数据来源：成员管理（SysUser：orgName / deptName / identity / employeeNo）

4.4 岗位分组明细
--------------------------------------------------------------------------------
分组 1：项目团队（3 岗）
  1) 项目联系人 *     字段键 contact
  2) 项目负责人 *     字段键 leader
  3) 技术负责人 *     字段键 techLeader

分组 2：责任专家（3 岗）
  4) 项目主管 *       字段键 supervisor
  5) 一级总师 *       字段键 chief1
  6) 二级总师 *       字段键 chief2

分组 3：管理团队（4 岗）
  7) 总部处室处长 *   字段键 hqDirector
  8) 总部处室主管 *   字段键 hqSupervisor
  9) 单位科技部长 *   字段键 unitTechDirector
 10) 单位科技主管 *   字段键 unitTechSupervisor

分组 4：财务团队（3 岗）
 11) 总部财务主管 *   字段键 hqFinance
 12) 单位财务部长 *   字段键 unitFinanceDirector
 13) 单位财务主管 *   字段键 unitFinanceSupervisor

五、页底说明
--------------------------------------------------------------------------------

六、保存校验规则（现网）
--------------------------------------------------------------------------------
保存前按序校验，不通过则 Message 提示并中止：
  1) 项目名称非空
  2) 是否需要审批已选
  3) 项目渠道（来源）已选
  4) 一级专业、二级专业已选
  5) 责任单位/牵头单位已选
  6) 牵头单位主要工作内容非空
  7) 13 个申报岗位均已选人

通过后：
  - 新建 → POST /api/declarations（状态 DRAFT，生成申报单号 SByyyyNNNN）
  - 编辑 → PUT /api/declarations/:id
  - applicant（列表「申报人」）取 posts.contact（项目联系人展示文案）
  - orgName 取 leadOrgName


七、列表页与后续动作（关联，非填报表单本体）
--------------------------------------------------------------------------------
列表列：申报单号 / 项目名称 / 项目层级 / 渠道类别 / 责任单位 / 一级专业 /
        申报人 / 申报日期 / 状态 / 当前节点 / 操作

状态：草稿、已提交、审批中、已通过、已驳回、已撤销、已归档

操作（更多）：
  - 编辑：回填本沉淀全部字段（含 posts）
  - 查看：打开「申报材料清单」（按渠道锁定非本渠道材料）
  - 提交审批 / 审批通过 / 撤销
  - 立项备案：生成项目主表；同步名称、渠道、责任单位、起止时间、目标、
              牵头工作内容、申请经费、一二级专业等；申报状态变为已归档
