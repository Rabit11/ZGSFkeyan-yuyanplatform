# 项目申报 / 立项备案审签改动报告

## 修改范围

仅调整立项阶段的项目申报审签、申报待办及申报办结后进入立项备案的衔接；实施、验收、经费、成果转化流程未修改。

## 主要修改

- 新增版本化申报流程目录：`declaration-workflows.json`，前后端各一份，按渠道编码选择模板。
- 后端新增 `DeclarationWorkflow`，提交、审批、待办均使用同一模板；新申报把流程版本写入岗位快照备注，旧在途数据继续使用兼容固定链。
- XX25 专项移除单位财务部门负责人节点。
- 科技周、 大飞机研究院、先进材料创新联盟、商飞—波音分别使用需求文档中的专用链；无需审批渠道使用“本单位科技部审批 → 自动报备归档”。
- 项目生命周期申报流转图按申报渠道显示实际节点和指定人员。
- Mock 新建、提交、审批、待办同步渠道流程。
- 增加全部渠道模板及 Mock 自动流转测试。
