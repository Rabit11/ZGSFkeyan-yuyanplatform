# yzh 立项流程定向合并

来源：origin/yzh，2cdd4f8。基线：82215eb。

按用户要求只合入立项业务流程和申报成员填写，保留当前页面布局、样式、审核意见及退回交互。其他模块与全站样式不合入。

新申报采用 yzh 固定链：负责人 → 承担部门负责人 → 二级总师 → 单位财务 → 单位科技 → 单位分管领导 → 一级总师 → 总部科研项目处。配置为无需审批/直接报备的渠道仍先负责人审核。成员填写采用 yzh 四组14岗，材料仍按渠道生成。

使用新增 yzh-v1 / yzh-report-v1 流程版本保存新申报，历史流程版本不改写，以免在途申报失效。立项备案沿用现有办理界面和团队回写。

验证：新链与报备链、历史渠道链兼容、成员岗位、负责人首审、退回、审批锁定、备案衔接；构建、浏览器和隔离库验证后发布到既有AutoDL2。

验证结果：98项后端测试、4项前端流程测试、39项隔离接口检查通过。浏览器确认两次新建重置后均显示负责人首审及四组14岗；申报页面原CSS逐字一致。已部署AutoDL2，公网38个导入项目和6条原申报读取正常。
