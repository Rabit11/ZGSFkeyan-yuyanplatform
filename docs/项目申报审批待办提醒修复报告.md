# 项目申报审批待办提醒修复报告

日期：2026-09-14

## 一、问题范围

本次修复针对“项目台账 → 项目申报流转图 → 差异化线上审签”中，审批人登录后“待我审核”红色提醒偶尔不显示的问题。

## 二、已修改内容

### 1. 新增后端当前用户待办接口

文件：`backend/src/main/java/com/comac/rpm/modules/declaration/controller/DeclarationController.java`

- 新增 `GET /api/declarations/pending`。
- 只返回 `SUBMITTED`、`APPROVING` 状态的申报。
- 直接按当前用户和当前审批节点计算，不再依赖前端查询前 200 条记录后过滤。
- 同时读取 `proj_declaration_post` 和历史 `remark` 岗位快照。
- 继续兼容申报人、单位和身份兜底逻辑。

### 2. 修复单位分管领导岗位匹配

文件：

- `backend/src/main/java/com/comac/rpm/modules/declaration/controller/DeclarationController.java`
- `backend/src/main/java/com/comac/rpm/common/permission/FlowAuditGuard.java`
- `frontend/src/utils/flowActor.ts`
- `frontend/src/views/initiation/Declaration.vue`

“单位分管领导”现在同时匹配：

- 单位科技部长（`unitTechDirector` / `unitHead`）
- 单位科技主管（`unitTechSupervisor` / `unitStaff`）

前端待办判断和后端审批权限保持一致。

### 3. 前端改用专用待办接口

文件：

- `frontend/src/api/modules.ts`
- `frontend/src/stores/pending.ts`
- `frontend/src/views/initiation/Declaration.vue`

- 新增 `declarationApi.pending()`。
- 顶部红色提醒和申报页“待我审核”统一使用该接口。
- 移除 `size: 200` 的隐式截断问题。

### 4. 增加自动刷新

文件：`frontend/src/layouts/BasicLayout.vue`

- 登录后立即加载待办。
- 每 30 秒自动刷新一次。
- 用户切换或退出登录时清理旧定时器。
- 页面卸载时清理定时器，避免重复轮询。

### 5. 财务待办独立容错

文件：`frontend/src/stores/pending.ts`

当 `/api/fund/reviews/pending` 失败时，只将财务待办视为 0，不再清空项目申报、维护和里程碑待办。

### 6. Mock 支持按用户模拟待办

文件：`frontend/src/mock/index.ts`

- 新增 `/declarations/pending` Mock 路由。
- 按当前登录用户、审批节点和岗位快照过滤。
- 支持历史 `remark` 快照。
- 支持单位分管领导两种岗位配置。

## 四、上线后建议验证

1. 用项目负责人提交一条申报。
2. 登录下一位审批人，确认 30 秒内出现红色提醒。
3. 审批通过后确认上一位提醒消失、下一位提醒出现。
4. 检查历史申报中仅有 `remark` 岗位快照的记录。
5. 财务账号下模拟经费接口异常，确认项目申报提醒仍保留。

本次修改不需要新增数据库表；已存在的 `proj_declaration_post` 表继续作为新数据的岗位权威来源。
