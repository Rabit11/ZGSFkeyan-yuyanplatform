## 1. 平台是什么

公司级科研预研 **经营管理平台**（COMAC / 商飞风格），不是实验室管理系统，也不是指挥舱大屏单独产品。

平台做三件事：

1. **一本账**：项目从申报到转化的主数据、材料、审批、预警集中归集。
2. **全过程留痕**：谁填、谁交、谁审、谁驳回，都能追溯。
3. **差异化适配**：按项目渠道/层级自动开放材料栏和审签链，锁定无关栏。

平台 **不替代** 项目团队做具体科研，也 **不替代** 专业管理部门的法定职责。

全生命周期（台账顶部固定 6 段，全渠道统一）：

```
01 项目申报 → 02 立项备案 → 03 实施阶段 → 04 项目验收 → 05 成果转化 → 06 项目完成归档
```

侧栏菜单是 **办理入口**；台账生命周期条是 **单项目进度视图**。两者数据必须同源。  
渠道内部子步骤（如民机科研：建议书申报→…）展示在概览「渠道流程」，**不替代** 顶部 6 段。

## 3. 怎么把这个平台做优秀（历史对话共识）

优秀不靠换框架，靠把下面几条做严。

### 3.1 先定口径，再写代码

1. 业务图（draw.io / 流转方案）→ 节点责任人与材料 → 权限矩阵 → 接口与表 → 页面。  
2. 截图/附件口径与代码不一致时，**以经确认的流程图 + 权威花名册/字典为准**，不要用演示假名回填。  
3. 台账 6 段生命周期、渠道子步骤、办理页、流转弹窗，必须同一套状态机，禁止两套文案。

### 3.2 权限是四层同时成立，不是「进得了菜单」

1. **登录身份数据范围**：全公司 / 本单位 / 本人关联项目 / 仅经费。  
2. **项目岗位办理权限**：在该项目担任什么岗、有哪些权限码。  
3. **流程节点指派**：审批只能由当前节点绑定的 **姓名+工号** 办理。  
4. **业务状态**：草稿可改、提交后锁定、驳回可补正、已批必须走变更。

因此：

- 看得到页面 ≠ 可以编辑  
- 有某项权限 ≠ 可以代替当前审批人审核  
- 参与项目 ≠ 可以改全部字段  

待办必须写清：项目、事项、截止时间、当前责任人、下一步动作。

### 3.3 主数据只认权威源

| 对象 | 权威源 | 禁止 |
|---|---|---|
| 人员姓名/工号 | `人员花名册-权威口径.txt` + `frontend/src/constants/personnel.ts` + `personnel_roster_v1.sql` | 截图里的「林晓琴」等演示名、流转图写死姓名 |
| 一级/二级专业 | 附件 1 专业字典（skill：`ky-major-dictionary`） | 自由输入、编码与名称对不上 |
| 项目渠道 | `proj_channel`（层级、材料栏、流程节点） | 页面写死材料清单 |
| 金额 | `DECIMAL(18,2)`，单位 **万元** | 混用元/万元 |
| 已批数据 | 变更流程 | 后台直接改里程碑日期、经费、核心指标 |

选人控件：下拉 **默认只推荐对应岗位**；用工号搜索时再放开全员。展示两行：姓名工号 + 单位/部门·任职。

### 3.4 渠道差异化，不要做「万能大表」

- 选择项目来源后，系统 **自适应展示对应附件栏**，非本渠道栏 `locked=1`，不可编辑。  
- 审签链按国家级 / 地方级 / 公司级差异化；无需审批走「直接线上报备」。  
- 验收材料同样按来源分级：国家级 MJKY 开单位/公司/国家三级；地方专项开单位/属地主管；公司自研开单位/公司。

### 3.5 流转图是产品，不是装饰图

- 默认：当前节点条 + 简洁链（折叠已办）。  
- 用户主动点「展开完整审批泳道」再出全图。  
- 打开弹窗必须 **拉最新接口**（团队、岗位、材料上传状态），禁止写死人员/清单。  
- 里程碑流转按 **该项目编制清单实际节点** 动态出条，不要预置一堆「未到节点」。

### 3.6 UI 必须像商飞经营管理类系统

强制：

- 标题栏商飞蓝 `#0048A0`，主色 `#0064EF`  
- 浅色后台（Ant Design Pro of Vue 口径）  
- 列表表头/行高 55px，默认控件高 32px  

禁止：紫粉渐变、经营管理主站做成深色、随意换主色。

深色「科研预研信息管理大屏 / 预研指挥舱」可以保留暗色，但必须 **嵌在现有壳层里**（侧栏+顶栏仍在），不要整页跳走把框架卸掉。可视化驾驶舱走浅色日常管控。

### 3.7 交互与科研合规

| 场景 | 标准做法 |
|---|---|
| 轻成功/弱错 | Message，不打断 |
| 高危不可逆 | Modal 二次确认 |
| 超期改里程碑/经费/核心指标 | 只能走 **项目变更** |
| 验收未过前置 | 按钮可点但必须展示红点清单，禁止静默灰掉 |
| 导入 Excel | 先预校验批次，用户确认后才入库；预览 ≠ 台账已变 |
| 空状态 | 无权限 / 无数据 / 筛空 / 异常都要有可行动文案 |

四色预警（全局共用）：临期黄、超期红；转化另有「到期前 30 天黄 / 超期红」，推送责任部门与管理团队。

### 3.8 质量闭环

- 改完同步 6006，用公网账号走一遍主路径。  
- 只读巡检：`给会冉/qa/task-flow-smoke.mjs`（默认不提交、不审批、不改数）。  
- 灌库必须指定 utf8mb4，否则中文项目名会乱码。  
- 后端 8080 挂了，前端会报 `backend unavailable: connect ECONNREFUSED`——先重启后端，不要当前端逻辑 bug 改一圈。

## 4. 业务主线（按阶段）

### 4.1 立项阶段（申报 + 备案）

主路径：

1. 立项阶段入口：项目申报 / 项目立项  
2. 选择项目来源 → 自适应附件栏，锁定无关项  
3. 项团上传审批全套材料（建议书/申请书/任务清单/评审意见等）  
4. 是否转办填报：是 → 二级单位管理部门转办 → 项团补充；可驳回  
5. 是否需要审批：需审批走渠道多级审签；无需审批 → 直接线上报备  
6. 通过后：申报办结，数据同步台账  
7. 上传立项佐证（批复/任务书/批准通知/合同等）→ 总部科技部备案归档  
8. 立项阶段办结 → 进入实施  

申报审签补充口径（多次改过）：

- 审核链含 **项目承担部门负责人**，顺序示例：项目负责人 → 项目承担部门负责人 → 二级总师 → …  
- 「是否转办填报」以产品最新页为准（有一轮要求申报表补「项目承担部门负责人」后去掉该判断）。改之前先对 6006 现网，不要两套流程图打架。

图与方案：`给会冉/立项阶段流转图/`、`给会冉/项目申报流转图/`、`给会冉/立项备案流转图/`。

### 4.2 实施阶段

并行业务域（五列泳道，**不设「项目发表」列**）：基本信息 | 实施管理 | 项目经费 | 监控核查 | 评估结论。

要点：

- 立项回显建主表 → 项团补录 → 二级内部审核 → 总部备案。  
- **里程碑编制** 与 **销项** 是两页：编制定节点数量、名称、交付物类型、计划日期；销项才上传凭证闭环。  
- 计划：CMOS 自动导入，不要求人工填报。  
- 经费：节点预算 → 两级财务 → 闭环后核销；**项目执行账与总部预算账两套独立、互不联动**。  
- 变更是跨泳道唯一调整出口。  
- 办结条件（进验收）：里程碑全闭环 + 关键计划办结 + 经费核销达标 + 评估无阻塞不合格 + 无未结重大变更。

图与方案：`给会冉/实施阶段流转图/`。

### 4.3 项目验收

入口：发起验收并上传佐证、评审结论。

前置闸门（不满足禁止提交）：

- 全部里程碑闭环  
- 外协交付物验收合格 / 核心交付物齐套  
- 节点经费匹配核销完毕  

（目标口径还含「无未闭环不合格评估」。现网 check 与目标清单以代码 `Acceptance` 接口为准，展示必须列出 checks。）

审批（图片口径）：

- 公司级：项目团队 → 二级单位管理团队初审（查完整性、内部预验收，可驳回整改）→ 总部管理团队终审  
- 国家级 / MJKY 重大：增加 **责任总师技术复核**  

办结后：开启 **30 天** 倒计时提醒参研单位评价；外协评价从 **外协合同验收完成日** 起算。  
「指标办归档」只归档本阶段材料，不等于生命周期 06。

图与方案：`给会冉/项目验收流转图/`。

### 4.4 成果转化

1. 承接验收已交付成果；超计划转化时间自动预警  
2. 前置：仅 **「已交付」** 交付物可纳入成果包；系统生成全局唯一成果编号并关联项目  
3. 项团填报转化方式/形式/计划时间，上传成效佐证  
4. 二级单位审核（可驳回修改，全程留痕）→ 总部备案（全量归档，**无二次审批**）  
5. 数据双向同步台账与看板，进展回写交付物  
6. 四色进度管控；成效纳入后评价，作为后续立项/资源/成果管理依据  
7. 产出到落地全链路闭环  

图：`给会冉/成果转化流转图/`。

### 4.5 表单维护（台账工具，不是表单设计器）

- 维护预研项目总表 / 按项目类型专项分表。  
- Excel 导入先入 **预校验批次**，确认「合并入库」后才进台账。  
- 只停在预览、不点确认，驾驶舱/台账/大屏都不会变。  
- 校验含：必填、经费关系、专业字典级联、日期先后、批次内唯一标识。  
- 8092 独立库与平台主库禁止混卷；台账要拷进主库。  
- 系统管理员进超管页；业务岗（如王建国）按成员管理授予的「表单维护」范围进入，不是同一页面。

说明：`给会冉/表单维护说明/表单维护页面功能说明.txt`。

登录：JWT HS256 + Redis `rpm:token:{jti}`；登出 DEL。废除纯 `x-user` 共享口令。
