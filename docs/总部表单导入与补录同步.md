# 总部表单导入与补录同步

- 总部责任处室处长（hqHead）和总部科研项目主管（hqStaff）可从系统管理 → 表单维护进入。
- 总表、分表默认合并导入，预览确认后写入数据库，来源标记 FORM_MAINT。负责人及来源渠道应准确填写。
- 总部编辑使用既有台账更新接口；进入补录后仍受源数据锁定约束。管理员专属删除、清空、全量替换按钮不对总部开放。
- 导入项目同步显示在有权限人员的台账以及领导座舱、看板。负责人从导入项目补录 → 我的补录维护对应渠道材料。
- 补录草稿私有，提交后可查看待审核状态；单位与总部审核通过后，已审核信息进入台账展示与看板统计，附件在项目详情对应标签下只读展示和下载。
- 保持数据同源：补录的审核快照用于展示投影，不向业务表重复插入统计记录。

## 验证
- 两类总部账号真实导入入库，负责人及领导能按权限查询。
- 隔离数据库验证补录持久化、草稿不可见、审核人员不可编辑、单位/总部审批、已审核台账/详情/看板投影。
- 隔离对象存储验证附件上传、草稿下载限制、审批后领导下载。
- 真实浏览器验证两个总部账号访问、Excel导出及再次导入预览；负责人及公司领导访问导入路由被限制。
- 前端构建与权限测试通过。生产库不写测试数据，保留用户清理结果。
