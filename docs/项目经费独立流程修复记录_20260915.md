# 项目经费独立流程修复记录

## 对齐依据

原细化需求文档含里程碑绑定描述；按用户后续明确指令，预算（含原节点预算）及核销取消里程碑关联与闭环前置条件。其他财务职责保留。

## 最终流程

项目团队填写项目年度预算 → 二级单位财务审核 → 总部财务复核备案 → 单位财务上传付款凭证并核销 → 经费看板同步。

- 按项目、年度、预算项维护；无里程碑也可填报。
- 团队暂存、负责人提交；单位财务审核、总部财务备案；审核只处理状态，不改金额、年度及名称。
- 拒绝跳级备案、审核中删除和已备案直接修改；退回后在对应节点补正。
- 单位财务按实际费用及真实凭证核销；发生年度须有已备案预算。草稿可继续填报，已核销不可直接改写，红冲保留历史且防止重复。
- 项目负责人和领导可在授权范围查看；无关人员不可读取项目经费。
- 详情生命周期节点仍只读，业务办理仍从左侧功能入口进入。

## 兼容

不做破坏性数据库迁移。旧 milestone_name 列保存预算项名称，API 增加 budgetName 别名。新预算和新核销不写入里程碑关联；历史关联与记录不删除。总部独立预算管控模块保持原有业务。

## 验证

- 后端 96 项测试通过，含新增 11 项经费测试；依赖外部环境的 TransformIntegrationTest 未在该单元测试命令中运行。
- 独立数据库、MinIO桶、Redis库及JWT上的 30 项接口检查通过，包括预算提交、两级审核、退回、无里程碑核销、草稿续填、重复凭证和重复红冲。
- 浏览器验证负责人可保存预算，单位财务可进入核销，领导不可填报；无 JavaScript 运行错误。
- 前端生产构建通过。

发布前备份数据库，发布失败恢复上一服务版本；发布后复核公网登录、台账、详情、补录信息及经费读取。

发布结果：已部署到 AutoDL2 6008 端口，公网经费资源、登录、38 个导入项目台账及补录读取通过；隔离测试库、存储桶与测试会话已清理。
