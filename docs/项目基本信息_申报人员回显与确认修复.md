# 项目基本信息：申报人员回显与确认修复

## 行为
- 恢复基本信息草稿读取、保存、提交、审核及待审核列表接口。
- 平台立项项目使用备案时从申报写入的正式团队，按岗位编码回显；已保存草稿优先。
- 使用系统人员目录供负责人选择修改，保留当前项目中目录之外的已有人员。
- 保存草稿不直接修改正式团队；负责人再次提交确认，按现有审批链审批通过后更新台账。
- 审核人员可查看和审批，不能编辑团队。草稿读取失败时停止编辑。
- 表单导入项目仅展示实际已有人员，缺失岗位由负责人补充，不生成虚构人员。
- 保持原页面布局，增加团队来源与确认提示。

## 验证
- 前端接口测试 2 项通过，覆盖四个草稿动作及待审核读取。
- 隔离浏览器验证 5 组通过：14 岗位回显、目录选择与草稿重载、负责人提交、审核只读、加载失败禁止编辑。使用模拟接口，不向生产库写测试数据。
- Vite 构建通过；基本信息及其待审核页面无类型错误。全项目类型检查仍有其他模块既有接口缺失（申报 pending、评估、里程碑及经费撤销等），不宣称全项目检查通过。
- 线上只读核验：登录、38 条项目记录、人员目录、草稿读取、基本信息待审核接口正常。
- 后端与数据库未修改；保留旧版前端以便回退。
