# 多类别、多对象选择与独立填写

本轮根据明确需求修正了页面交互：在同一项目的一份变更申请中，直接多选多个变更类别与各自对象，确认后一次展开对应的内容填写区。上一版“单选一个字段，再逐项加入”的界面已由此流程替代。后端继续使用已有的整单审批、版本记录和原子回写能力。

## 实际入口和操作

在现有平台地址打开“项目变更 → 发起变更”：

1. 选择项目及变更类型。项目业务调整与数据纠错仍按原审批规则分别申请。
2. 点击显著的“多选变更类别与对象”按钮。
3. 在弹窗第一步同时勾选多个类别，例如“里程碑延期”“交付物”“经费调整”。每个类别标明可选项数和法务要求。
4. 在第二步多选各类别下的具体对象。同类下允许选多条记录，例如两个不同的里程碑；可搜索对象、全选当前显示的本类对象，并在侧边核对已勾选清单。
5. 点击“确认选择 N 项”。主页面自动为每一项展开自己的当前值和调整后内容输入：日期选择器、金额输入（万元）、文本框或渠道选择器。无需再逐项加入或切换编辑对象。
6. 分别填写，查看“已填 N / M 项”。漏填或格式错误会在对应项下标明，整份申请不会部分保存。
7. 填写共同标题、缘由，按需要指定法务，保存整份草稿并上传材料。
8. 点击“一次提交 N 项”。所有对象归属同一个申请编号，通过同一条审批路径，最终一起生效。

“增减变更类别与对象”可重开选择窗口；保留对象的输入不丢失。移除已经填写的对象要确认，取消弹窗则不改变主表单。可以取消全部选择并确认“清空已选对象”；空清单不能保存或提交。类型在已有选择时锁定，清空后可重选。

## 版本与流程

每次保存仍保留整份内容版本；在“版本与履历”中查看。审批中锁定内容，退回后可修改任意所选对象并重新提交。右侧与办理框展示通过后的下一办理方、姓名/工号和退回接收人。任一经费、周期、外协项被选中即要求法务；不能把重大变更混入其他类别绕过法务。

测试模式 S09 现在直接展开“核心指标＋经费”两个类别的独立填写区，并提供新的多选操作脚本。进入、登录及 API 继续使用原平台同源地址，未增加端口或隧道映射。

## 修改位置

- `frontend/src/views/implement/change/ChangeObjectPicker.vue`：多类别勾选、分组对象多选、搜索、全选、待确认清单。
- `frontend/src/views/implement/Change.vue`：多选入口、按对象生成不同控件、逐项错误和完成数、整单提交数量。
- `frontend/src/views/implement/change/useChangeWorkbench.ts`：整批选择、保留已输入内容、逐项校验、完整 items 请求、消除旧单字段摘要覆盖首项的风险。
- 演练场景与测试脚本同步调整；后端接口、审批权限、其他业务页面和原资料不改。

## 验证范围

`qa/change/multiselect-browser.mjs` 从原平台入口进入真实隔离演练库，执行以下场景：

| 场景 | 核验内容 |
| --- | --- |
| D01 | 同时勾选 3 个类别、4 个对象：两个不同里程碑、交付物名称、总经费 |
| D02 | 自动出现两个日期控件、一个文本框、一个金额框；漏填不发保存请求；保存只产生一个申请且关联 4 项 |
| D03 | 取消已填写类别需要确认，取消操作保留原 4 项与输入 |
| D04 | 重开编辑并保存下一版，首项不被旧摘要覆盖；单次提交请求携带同一申请 |
| D05 | 单位→法务→总部实际审批；前序保持原数据，终审同时更新 4 项且只记录一次回写 |
| D06 | 数据纠错也可多选基本信息、年度任务两个类别；窄屏能填写，无模块横向溢出 |
| D07 | 可确认清空全部对象并重新选择类型，空清单不能保存或提交 |

其他现有脚本的对象选择和输入定位同步到新页面。`qa/change/batch-browser.mjs` 为新多对象浏览器脚本的兼容入口。`qa/change/run-lab.py` 包含新增脚本；本轮实际日志、截图、请求证据位于 `deploy/change-multiselect/`，不沿用旧界面报告作为本轮结果。

## 本轮实际结果（2026-09-14）

全部通过：新增多对象浏览器流程 7 组、原页面操作 20 组、演练隔离/样式 13 组、单地址真实流程 5 组、最终场景与输入标签 2 组、其他页面只读检查 11 项、前端单元测试 26 项。类型检查和前端构建通过，当前构建已由原服务入口提供。

实际请求证据：勾选 3 个类别、4 个对象，第一次保存仅发送一个创建请求且 `items` 含 4 项，之后编辑仍使用同一申请 ID；最终仅发送一次提交请求。单位、法务、总部完成后，两个里程碑日期、交付物名称、总经费同时更新，且只有一次回写事件。

保留的真实演练样例：项目 `LAB_PROOF_MULTI_107`，申请 ID `187`。测试模式搜索“多类别多对象一次提交”可查看该申请的全部对象、内容版本和审批履历。样例只在隔离演练库中保留。

检查了 378 个已有文件的范围快照，约定范围外改动为 0，原始 Office 文件保持不变。浏览器验证使用原入口，另验证了单地址 HTTPS 模拟；未获得用户实际隧道 URL，不宣称已经直连验通该 URL。
