# 接口清单

> 基础路径 `/api` · 认证方式 `Authorization: Bearer <token>`
> 统一响应体：`{ "code": 0, "msg": "ok", "data": ... }`（`code` 非 0 表示失败）
> 分页响应体：`{ "code": 0, "data": { "records": [], "total": 0, "page": 1, "size": 10 } }`

## 认证 `auth`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 登录，返回 token 与用户角色 |
| GET | `/api/auth/profile` | 当前用户信息 |
| POST | `/api/auth/logout` | 退出登录 |

## 数据字典 `dict`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/dict/{type}` | 按类型查询字典（项目层级、交付物类型、转化方式等） |
| GET | `/api/dict/channels` | 渠道列表，可按 `levelCode` 过滤 |
| GET | `/api/dict/channel/{id}` | 渠道详情，含流程节点数组与材料清单 |

## 项目一本账 `projects`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/projects` | 分页查询，支持 keyword / levelCode / channelId / status / warnColor / orgId |
| GET | `/api/projects/{id}` | 详情（含参研单位、团队、年度计划） |
| GET | `/api/projects/{id}/overview` | **全周期详情聚合**（里程碑、计划、经费、评估、变更、验收、交付物、评价、转化、后评价） |
| POST | `/api/projects` | 新增，自动生成项目编号 |
| PUT | `/api/projects/{id}` | 更新 |
| DELETE | `/api/projects/{id}` | 逻辑删除 |
| POST | `/api/projects/{id}/submit` | 提交备案 |
| POST | `/api/projects/{id}/refresh-status` | 重算四色状态 |
| GET | `/api/projects/export` | 导出（返回全部符合条件的记录） |

## 里程碑 `milestones`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/projects/{id}/milestones` | 列表，可按 `year` 过滤，实时刷新四色 |
| POST | `/api/milestones` | 新增 |
| PUT | `/api/milestones/{id}` | 更新 |
| DELETE | `/api/milestones/{id}` | 删除 |
| POST | `/api/milestones/{id}/close` | **闭环销项**（校验已上传佐证材料） |
| POST | `/api/milestones/{id}/delay` | 延期申请（拒绝直接修改，引导走变更流程） |

## 经费 `fund` / `hq-fund`

**项目级经费执行账**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/projects/{id}/fund/budgets` | 节点预算列表 |
| POST/PUT/DELETE | `/api/fund/budgets[/{id}]` | 预算增删改 |
| GET | `/api/projects/{id}/fund/payments` | 付款流水 |
| POST | `/api/fund/payments` | 登记付款/支出 |
| POST | `/api/fund/payments/{id}/writeoff` | 核销 |

**总部经费预算管控（独立体系）**

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/hq-fund/budgets` | 年度预算盘子查询/新增 |
| POST | `/api/hq-fund/budgets/{id}/lock` | 预算锁定 |
| GET/POST | `/api/hq-fund/quotas` | 单位额度查询/新增 |
| GET/POST | `/api/hq-fund/transfers` | 拨付执行查询/申请（校验额度上限） |
| POST | `/api/hq-fund/transfers/{id}/audit` | 双审（通过后更新额度与台账） |

## 立项申报与备案 `declarations`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/declarations` | 分页查询 |
| GET | `/api/declarations/{id}` | 详情（含材料清单） |
| POST | `/api/declarations` | **新建申报 → 按渠道自适应生成材料栏** |
| PUT | `/api/declarations/{id}` | 更新 |
| GET | `/api/declarations/{id}/materials` | 材料清单（含 `locked` 标志） |
| POST | `/api/declarations/{id}/materials` | 上传/替换材料（版本号自增） |
| POST | `/api/declarations/{id}/submit` | 提交审批 |
| POST | `/api/declarations/{id}/audit` | 审批（驳回退回初始节点并留痕） |
| POST | `/api/declarations/{id}/revoke` | 撤销（仅填报人） |
| POST | `/api/declarations/{id}/filing` | **立项备案 → 生成项目主表并进入实施阶段** |

## 验收 `acceptance`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/acceptance/{projectId}` | 验收详情 + 分级材料栏（非对应层级 `locked`） |
| POST | `/api/acceptance/{projectId}/check` | **前置条件校验**（4 项检查） |
| POST | `/api/acceptance/{projectId}/submit` | 提交申请（校验未通过则拒绝） |
| POST | `/api/acceptance/{projectId}/materials` | 上传分级材料 |
| POST | `/api/acceptance/{projectId}/audit` | 办结（开启 30 天协作单位评价倒计时） |
