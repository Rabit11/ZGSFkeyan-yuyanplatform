6008端口“项目台账”页面显示信息梳理
====================================
一、页面定位
============

项目台账是平台统一的项目查询与汇总入口，用于：

1. 展示当前用户有权查看的科研预研项目。
2. 按项目层级、渠道、类型、专业、单位、状态和预警进行查询。
3. 汇总当前查询结果的项目数量和经费规模。
4. 通过四色状态快速识别项目风险。
5. 展示项目周期、里程碑、经费、负责人、交付物、协作单位、成果转化和下一节点摘要。
6. 点击项目进入全生命周期详情。
7. 对具备权限的人员提供项目新增、编辑、删除、导出和撤回入口。


二、页面整体结构
================

页面从上到下由五部分组成：

1. 角色视角提示条。
2. 查询筛选与列配置工具栏。
3. 当前结果汇总与四色预警统计。
4. 项目台账表格。
5. 具备权限时注入的台账操作按钮和行操作菜单。

文字结构示意：

┌────────────────────────────────────────────────────────────┐
│ 当前角色视角提示（部分角色显示）                            │
├────────────────────────────────────────────────────────────┤
│ 搜索 │ 层级 │ 渠道 │ 司局/处室 │ 项目类型 │ 专业 │ 单位 │ 状态 │ 预警 │
│                                             [列配置] [导出Excel] │
├────────────────────────────────────────────────────────────┤
│ 共N项 │ 经费合计N万元 │ 红N │ 黄N │ 蓝N │ 绿N │ 角色范围标签 │
├────────────────────────────────────────────────────────────┤
│ 项目名称 │ 编号 │ 层级/渠道/类型 │ 专业/单位 │ 周期 │ 状态 │ ... │
│ 项目记录……                                            [行操作] │
└────────────────────────────────────────────────────────────┘


三、角色视角提示
================

页面顶部会根据部分登录角色显示橙色提示条或蓝色范围标签。

1. 责任总师
   - 顶部提示：“技术把关 · 整栏独有”。
   - 只显示本人被指定为一级总师或二级总师的经手项目。

2. 总部财务主管、单位财务部长等非只读财务角色
   - 顶部提示：“经费管控 · 财务独有”。
   - 汇总区显示“项目台账 · 经费视角”。

3. 单位财务主管
   - 顶部提示：“经费管控 · 无总部拨付、无修改”。
   - 汇总区显示“项目台账 · 经费视角”。

4. 项目团队
   - 顶部提示：“我的科研 · 仅本人关联项目”。
   - 汇总区显示“仅显示本人关联项目”。

5. 项目联系人
   - 后端同样按本人关联项目限制。
   - 当前顶部提示判断主要针对team角色，联系人可能不显示同样的橙色提示，但数据范围仍然受限。

6. 公司领导
   - 汇总区显示“领导只读：看板 / 台账 / 成果转化台账”。
   - 可以查看全公司台账，不提供台账编辑能力。

7. 总部管理人员
   - 显示全公司权限范围内的项目。

8. 单位管理人员
   - 显示本单位项目及本人另行担任项目岗位的项目。

9. 系统管理员
   - 显示全平台项目。
   - 具备台账运维管理入口。


四、查询和筛选区域
==================

项目台账当前提供以下10类查询条件。

4.1 项目关键词
------------

显示形式：带搜索图标的文本输入框。

占位文字：项目名称 / 编号。

查询范围：
1. 项目名称。
2. 项目编号。


4.2 项目层级
------------

选项包括：
1. 全部层级。
2. 国家级。
3. 地方级。
4. 公司级。

实际候选项优先从平台级联字典加载。


4.3 项目来源/渠道
----------------

显示：全部渠道或指定渠道。

渠道候选值由当前层级决定，与层级筛选联动。


4.4 司局/处室
--------------

显示：全部司局/处室或指定值。

作用：
1. 作为层级、渠道和项目类型之间的辅助筛选层。
2. 用于缩小渠道路径。
3. 当前说明注明该字段是辅助筛选，不单独写入标准Excel字段。


4.5 项目类型
------------

显示：全部项目类型或指定项目类型。

候选值由层级、渠道、司局/处室共同决定。


4.6 一级专业
------------

显示：全部一级专业或附件1专业字典中的指定一级专业。

选择一级专业后，会清空原二级专业筛选，并重新生成二级专业候选项。


4.7 二级专业
------------

1. 已选择一级专业时，只显示该一级专业下的二级专业。
2. 未选择一级专业时，显示全部二级专业候选。


4.8 单位
----------

显示：全部单位或指定二级单位。

筛选逻辑：
1. 项目牵头单位ID与所选单位相同；或
2. 表单台账的责任单位、管理/需求单位中包含所选单位名称或简称。

显示差异：
1. 项目团队role=team时不显示单位筛选框，因为数据已经限定为本人关联项目。
2. 其他角色可显示单位筛选，但后端仍只返回权限范围内数据。


4.9 项目状态
------------

选项：
1. 全部状态。
2. 申报中。
3. 立项中。
4. 实施中。
5. 验收中。
6. 已验收。
7. 已终止。


4.10 预警颜色
-------------

选项：
1. 全部预警。
2. 红色。
3. 黄色。
4. 蓝色。
5. 绿色。

用户也可以点击汇总区的四色数量直接筛选；再次点击当前颜色可以取消该筛选。


4.11 筛选联动和URL状态
---------------------

1. 层级、渠道、司局/处室和项目类型采用四级级联。
2. 选择上级后，下级候选项会按合法路径刷新。
3. 选择项目类型时可以反向补齐上级路径。
4. 所有筛选条件写入页面URL参数。
5. 复制当前页面链接，可以保留当前筛选组合。
6. 页面兼容旧版channel=id参数，并自动转换到新的层级、渠道、司局和项目类型参数。
7. 筛选条件变化后重新请求项目列表。


五、汇总信息区域
================

汇总内容随当前筛选结果实时变化。

5.1 项目数量
------------

显示格式：共 N 项。

含义：当前账号权限范围和当前筛选条件共同作用后的记录数量。


5.2 经费合计
------------

显示格式：经费合计 N 万元。

计算方式：当前结果中每个项目总经费total_budget求和。


5.3 四色预警数量
----------------

分别显示：
1. 红色项目数量。
2. 黄色项目数量。
3. 蓝色项目数量。
4. 绿色项目数量。

每个颜色由圆点和数量组成，并可点击筛选。


六、项目台账主表字段
====================

“项目名称”始终显示，另外13个信息列可以在“列配置”中显示或隐藏。页面初始状态默认全部显示。


6.1 项目名称（固定列）
--------------------

展示内容：
1. 项目风险颜色圆点。
2. 项目名称。

显示规则：
1. 名称使用单行截断。
2. 红色项目的颜色圆点带脉冲效果，突出风险。
3. 点击整行进入项目详情页。


6.2 编号
--------

展示项目编号code。

使用等宽数字样式，便于识别和对齐。


6.3 层级 / 渠道 / 类型
---------------------

该列分两行展示：

第一行：
1. 项目层级标签。
2. 项目来源/渠道。

第二行：
1. 司局/处室。
2. 项目类型。

层级颜色：
1. 国家级：主题蓝色标签。
2. 地方级：紫色标签。
3. 公司级：灰色标签。


6.4 专业 / 管理单位
-------------------

该列分两行展示：

第一行：一级专业 / 二级专业。

第二行：
1. 管理单位。
2. 牵头或责任单位简称。

其中“管理单位”主要来自渠道负责部门或表单台账管理信息；牵头单位来自项目lead_unit_id或表单责任单位。


6.5 项目周期
------------

展示内容：
1. 项目开始年月。
2. 项目结束年月。
3. 项目周期月数。

显示格式示意：
YYYY-MM – YYYY-MM
N 个月


6.6 状态
--------

使用状态标签展示项目生命周期状态：
1. 申报中。
2. 立项中。
3. 实施中。
4. 验收中。
5. 已验收。
6. 已终止。

颜色规则：
1. 已验收：绿色。
2. 验收中：黄色。
3. 已终止：灰色。
4. 其他推进状态：主题蓝色。


6.7 预警
--------

展示项目当前综合预警颜色和中文标签：
1. 红：逾期告警。
2. 黄：临期预警。
3. 蓝：正常推进。
4. 绿：已完成。

预警不是只根据项目主状态生成，还综合考虑：
1. 里程碑计划时间和完成时间。
2. 交付物约定期限和实际交付时间。
3. 成果包计划时间、实际时间和完成状态。

计算原则：
1. 下游任一受控对象存在更严重风险时，项目显示最严重颜色。
2. 项目主状态不能覆盖里程碑、交付物或成果转化的红黄风险。
3. 只有受控事项全部闭环，项目才显示绿色。
4. 已终止项目按现有代码显示绿色综合颜色，但项目状态标签仍显示“已终止”灰色标签，两者需要同时理解。


6.8 里程碑进度
--------------

展示内容：
1. 进度条。
2. 已完成里程碑数 / 里程碑总数。

进度计算：
1. 有里程碑时：已完成数量 ÷ 总数量。
2. 没有里程碑但项目已验收时：100%。
3. 其他没有里程碑的项目：0%。

进度条颜色与项目综合预警颜色一致。


6.9 经费拆分（万元）
-------------------

第一行：项目总经费。

第二行：
1. 国拨经费。
2. 自筹经费。

显示格式示意：
总经费数值
国拨 N / 自筹 N


6.10 年度预算 / 支出
--------------------

显示当前年度：
1. 年度预算。
2. 年度支出。

显示格式：年度预算 / 年度支出。

数据来自当前年度资金记录；没有对应记录时按0展示。


6.11 负责人
-----------

显示项目团队中的项目负责人姓名。

无负责人时，详情辅助脚本会把“待指定”等空白表达统一处理为“暂无”。


6.12 交付 / 协作
----------------

该列分两行展示：

第一行，交付物摘要：
1. 已交付数量 / 交付物总数量。
2. 无交付物时显示“暂无”。

第二行，协作评价摘要：
1. 已评价单位数 / 协作单位总数。
2. 如存在黑名单单位，追加“含黑名单”。
3. 无协作单位时显示“暂无”。


6.13 成果转化
-------------

展示成果转化汇总：
1. 成果包总数。
2. 已完成成果包数。
3. 或表单台账中的成果转化摘要。

有成果内容时使用主题色突出；无数据时显示“暂无”。


6.14 下一到期节点
----------------

展示最近一个尚未完成的里程碑：
1. 节点名称。
2. 距离到期天数或超期天数。

颜色提示：
1. 已超期：红色。
2. 30天内到期：黄色。
3. 30天以上：灰色弱提示。
4. 没有待办节点：显示“—”。

仅存在表单台账、尚未形成正式里程碑的实施中项目，以“计划结束”作为下一节点摘要。


七、列配置
==========

1. 点击“列配置”打开浮层。
2. 可分别勾选以下13列：
   - 编号。
   - 层级/渠道。
   - 专业/单位。
   - 项目周期。
   - 状态。
   - 预警。
   - 里程碑。
   - 经费拆分。
   - 年度预算/支出。
   - 负责人。
   - 交付/协作。
   - 成果转化。
   - 下一节点。
3. 项目名称固定显示，不能通过列配置隐藏。
4. 当前列配置仅保存在组件运行状态，刷新页面后恢复默认全部显示。
5. 当前主页面导出按钮没有把列配置作为参数传给导出接口，因此列隐藏只影响页面显示，不影响导出Excel字段范围。


八、表格交互与状态
==================

1. 页面加载时，项目列表未返回前显示加载状态或空白表体。
2. 没有符合筛选条件的项目时，显示：“没有符合筛选条件的项目”。
3. 表格区域支持横向滚动。
4. 表格最大高度约为视口高度减320px，超过后在表格区域滚动。
5. 整行可点击，进入/projects/:id项目详情。
6. 台账操作增强脚本会识别当前行，并在具备权限时提供：
   - 查看。
   - 编辑。
   - 删除。
7. 操作成功或失败通过右下角提示消息反馈。


九、台账管理操作的显示
======================

本节说明具备权限时页面额外出现的管理入口。普通只读人员不会看到或无法使用这些入口。

9.1 撤回上一步
--------------

1. 有台账编辑、删除或撤回权限时显示。
2. 当前没有可撤回操作时按钮禁用。
3. 悬停提示可撤回原因、时间和备份中的项目数量。
4. 确认撤回后，恢复上一步操作之前的项目台账、表单和维护数据。


9.2 添加项目
------------

1. 有项目台账新增权限时显示。
2. 点击后打开右侧“添加项目”抽屉。
3. 保存后同步项目台账、表单、驾驶舱和大屏相关数据。


9.3 删除全部
------------

1. 有台账删除权限时显示。
2. 弹窗显示当前将删除的项目数量。
3. 删除后同步清除表单、驾驶舱和大屏中的对应记录。
4. 删除前创建平台快照，可通过“撤回上一步”恢复。
5. 后端要求确认值DELETE_ALL，不能只依靠前端确认框。


9.4 行操作
----------

选择或点击一行后，增强菜单显示：
1. 查看：进入项目详情。
2. 编辑：打开项目台账编辑抽屉。
3. 删除：删除当前项目及其关联台账信息。

每条记录还携带canEdit和canDelete标记。即使用户总体上有台账权限，也可能因为记录不在授权范围内而不能编辑或删除该行。


十、添加/编辑抽屉显示字段
========================

10.1 项目基本信息
-----------------

1. 项目编号。
   - 新增时可填写，留空则自动编号。
   - 编辑时不可修改。
2. 项目状态。
3. 项目名称，必填。
4. 级别。
5. 项目来源/渠道。
6. 司局/处室。
7. 项目类型。
8. 一级专业。
9. 二级专业。
10. 责任单位。
11. 管理/需求单位。
12. 负责人。
13. 开始日期。
14. 结束日期。

10.2 经费情况（万元）
---------------------

1. 总经费。
2. 国拨经费。
3. 自筹经费。
4. 累计支出。
5. 其中商飞内部国拨。
6. 其中商飞内部自筹。
7. 2026年预算。
8. 2026年实际执行。

校验规则：
1. 总经费未填写、但填写了国拨和自筹时，自动以二者之和生成总经费。
2. 总经费必须等于国拨经费与自筹经费之和，允许误差不超过0.01万元。

10.3 目标与备注
---------------

1. 项目目标。
2. 年度目标。
3. 备注。

10.4 级联规则
---------------

1. 层级 → 渠道 → 司局/处室 → 项目类型。
2. 一级专业 → 二级专业。
3. 非法层级、渠道、司局和项目类型组合不能保存。
4. 非法专业组合不能保存。
5. 单位管理人员新增项目时，责任单位由后台强制为本人所属单位，不能跨单位创建。


十一、不同人员看到的数据范围
============================

1. 系统管理员
   - 全平台项目。

2. 公司领导
   - 全公司项目，只读。

3. 总部管理人员
   - 全公司项目。

4. 单位管理人员
   - 牵头单位为本单位的项目。
   - 本人被写入project_members的项目。
   - 本人在项目中担任任一岗位的项目。

5. 单位财务人员
   - 本单位项目。
   - 本人担任项目财务岗位或其他项目岗位的项目。
   - 页面以经费视角展示，具体写操作进一步受财务角色限制。

6. 项目负责人、技术负责人、项目主管、项目联系人
   - 本人存在于项目成员表的项目。
   - 本人担任项目岗位的项目。

7. 一级总师、二级总师
   - 本人被指定为对应总师岗位的经手项目。

8. 纯表单台账记录
   - 总部、管理员和领导按全量范围显示。
   - 单位账号按本单位匹配显示。
   - 其他人员按本人负责人或更新人匹配显示。


十二、导出Excel显示信息
======================

1. 页面显示条件
   - 前端主按钮只对管理角色和系统管理员显示。
   - 公司领导明确禁止导出。
   - 其他角色即使后端接口存在，也不在当前主页面显示标准导出按钮。

2. 导出范围
   - 导出当前用户有权查看的项目。
   - 保留当前URL中的层级、渠道、司局、项目类型、单位、状态、预警、关键词、一级专业和二级专业筛选。

3. 导出格式

十五、数据来源和同步关系
========================

项目台账列表由两类数据合并形成：

1. 正式项目库projects中的项目。
2. 表单维护总表中尚未正确关联正式项目、但当前用户有权查看的额外台账记录。

合并规则：
1. 页面加载前尝试把表单台账记录同步为正式项目。
2. 正式项目经过里程碑、经费、交付物、成果包、协作单位和项目成员信息富化。
3. 表单台账信息可覆盖或补充正式项目的专业、渠道、单位、经费和成果摘要。
4. 已经关联的表单记录不重复显示。
5. 无正式项目关联的额外表单记录转换为只读或可控台账行展示。

编辑和删除同步：
1. 在项目台账新增或编辑项目，会同步表单台账。
2. 删除项目会同步删除关联表单记录。
3. 驾驶舱和大屏使用同一项目数据结果。
4. 每次高风险修改前建立平台快照。


十六、主要接口
==============

1. GET /api/projects
   - 获取当前用户和筛选条件下的项目列表。

2. GET /api/projects.xlsx
   - 导出当前权限范围及URL筛选范围的Excel。

3. GET /api/projects.csv
   - 兼容旧CSV导出。

4. GET /api/projects/ledger-form
   - 获取新增项目抽屉所需字典、单位、状态和空白表单。

5. POST /api/projects
   - 新增项目台账记录。

6. GET /api/projects/:id/ledger-form
   - 获取指定项目编辑表单和当前记录权限。

7. PUT /api/projects/:id
   - 编辑项目台账。

8. DELETE /api/projects/:id
   - 删除单个项目及关联表单记录。

9. POST /api/projects/bulk-delete
   - 批量删除有权限的项目，返回删除数和跳过数。

10. POST /api/projects/delete-all
    - 删除当前权限范围内全部项目，要求DELETE_ALL确认。

11. GET /api/projects/undo-status
    - 获取当前是否存在可撤回操作及快照说明。

12. POST /api/projects/undo-last
    - 撤回上一步项目台账操作。

13. GET /api/projects/:id
    - 获取项目详情页全部展示数据和当前用户的项目岗位权限。


十七、显示规则和权限注意事项
============================

1. 页面只显示当前用户有权查看的项目，前端筛选不是权限过滤的替代品。
2. 公司领导、系统管理员和总部管理人员可以看到全公司或全平台项目，但写权限不同。
3. 单位管理和单位财务只能看到本单位及本人担任项目岗位的项目。
4. 项目团队和总师只看到本人关联或经手项目。
5. 能看到项目详情页签，不等于能点击办理按钮。
6. 项目具体写操作由18项项目岗位权限、流程状态和后台接口共同判断。
7. 财务人员以经费视角查看；单位财务主管明确为只读。
8. 项目台账中显示的“负责人”只是项目负责人，其他项目岗位需要进入项目详情“项目团队”查看。
9. 空字符串、“待指定”“未形成成果包”“0/0”等无效展示值会统一转为“暂无”或“—”。
10. 来自表单台账的项目可能尚未具备完整里程碑、计划、文档和项目团队信息，应显示合理空状态。


十八、当前页面显示方面的改进点
================================

1. 项目台账没有前端分页，当前权限范围项目较多时会一次加载全部记录。
2. 关键词输入变化会立即请求接口，未发现明显防抖处理，大量输入可能产生连续请求。
3. 列配置刷新后丢失，可考虑按用户保存。
4. 当前列配置不影响Excel导出字段，页面“所见列”和导出内容可能不一致。
5. 项目名称固定列没有真正CSS sticky声明，横向滚动后可能看不到项目名称。
6. 单位筛选只对role=team隐藏，项目联系人同样是本人项目范围却仍可能显示单位筛选，交互表现不完全一致。
7. 页面依赖额外脚本向React表格注入添加、编辑、删除和撤回功能，重构时应整合为同一Vue组件，避免DOM识别失效。
8. 行操作菜单通过项目名称或编号匹配DOM行，存在同名项目或列隐藏时的识别风险；Vue重构应直接绑定项目ID。
9. 已终止项目综合预警颜色按代码为绿色，而状态标签为灰色“已终止”，应增加文字解释以避免把终止误解为正常完成。
10. 详情后端定义“项目可视化”始终可见，但当前详情页签数组未直接展示该页签，需要核实实际入口并统一。
11. 主列表没有显式的“清空筛选”按钮，用户需要逐项取消或修改URL。
12. 主列表没有排序、分页、视图保存和批量选择功能。
13. 增删改操作虽然可撤回，但删除全部仍应突出影响范围、备份时间和恢复边界。


十九、Vue + Spring Boot迁移时必须保持的显示行为
================================================

1. 保留10类筛选条件及四级渠道路径联动。
2. 保留一级专业与二级专业联动。
3. 保留筛选条件写入URL，可复制筛选链接。
4. 保留当前结果项目数、经费合计和四色数量。
5. 保留固定项目名称及13个可配置摘要列。
6. 保留红色脉冲、状态标签、预警标签和临期/超期天数提示。
7. 保留里程碑进度、经费拆分、年度预算支出、交付协作和成果转化摘要。
8. 保留不同角色的范围提示和数据隔离。
9. 保留点击行进入项目详情。
10. 保留项目详情8个当前页签及其显示字段。
11. 保留表单台账与正式项目数据合并、去重和补充机制。
12. 保留新增、编辑、删除时与表单、驾驶舱、大屏同步。
13. 保留项目台账快照和撤回上一步。
14. 保留后台canEdit、canDelete和项目岗位权限判断。
15. 前端只能依据后端权限显示操作，不得自行扩大项目范围。


二十、页面验收清单
==================

1. 主列表
   □ 项目名称和13个可配置列显示正确。
   □ 预警、状态、进度、经费和摘要字段计算正确。
   □ 空值统一显示“暂无”或“—”。
   □ 点击项目进入正确详情。

2. 筛选
   □ 关键词可搜索项目名称和编号。
   □ 层级、渠道、司局、项目类型四级联动正确。
   □ 一级专业、二级专业联动正确。
   □ 单位、状态、预警筛选正确。
   □ URL能够完整恢复筛选状态。
   □ 四色统计可以作为快捷筛选。

3. 汇总
   □ 项目数量与当前结果一致。
   □ 经费合计与当前结果一致。
   □ 红黄蓝绿数量与表格记录一致。

4. 权限显示
   □ 领导全公司只读。
   □ 总部管理显示全公司项目。
   □ 单位管理只显示本单位和本人任职项目。
   □ 项目团队只显示本人关联项目。
   □ 总师只显示本人经手项目。
   □ 财务人员显示正确经费视角。

5. 管理操作
   □ 有权限人员显示添加、编辑、删除和撤回。
   □ 无权限人员不显示或不能调用写接口。
   □ 每行canEdit和canDelete生效。
   □ 删除和撤回同步表单、驾驶舱及大屏。

6. 详情页
   □ 头部基本信息、经费和进度正确。
   □ 概览、里程碑、计划、经费、交付物、协作评价、成果转化、审批归档内容完整。
   □ 项目团队和项目岗位显示正确。
   □ 附件下载受权限控制。
   □ 项目办理按钮受项目岗位和流程状态控制。


二十一、结论
============

6008端口项目台账页面展示的是“当前用户权限范围内的项目全景摘要”。主列表把项目身份、组织归属、专业、生命周期状态、风险、里程碑、经费、负责人、交付协作、成果转化和下一节点集中在一张表中；点击项目后，再展开为完整的项目生命周期详情。

后续改为Vue + Spring Boot时，不能只复刻表格外观。必须同时保留项目与表单台账的合并逻辑、不同人员的数据范围、四色预警计算、摘要字段计算、项目详情关联数据、行级编辑权限、跨模块同步和撤回机制，才能保证页面显示结果与6008当前平台一致。
