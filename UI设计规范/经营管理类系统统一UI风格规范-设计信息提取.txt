经营管理类系统统一UI风格规范 — 设计信息提取
================================================
来源：给会冉/最终版材料/经营管理类系统统一UI风格规范.pptx（共 35 页）
说明：以下内容按 PPT 可提取文字整理；配色/文字/圆角等页以图示为主，
文中标注「图示页」的条目结合同材料落地色与 Ant Design Pro of Vue 样例作补充。

一、规范定位与思路
- 遵循《企业应用软件界面设计规范》总体要求
- 以 Ant Design Pro of Vue 框架为样例，构建《公司经营管理类系统统一UI风格规范》

二、五项基本原则
1. 一致性：信息架构、界面逻辑、样式布局、操作方式保持一致，降低学习成本
2. 易用性：服务于功能，以用户体验为中心，简化视觉层级，减少视觉噪音，信息清晰、界面美观易用
3. 认知性：与人的视听触及认知习惯兼容，遵循已习惯的交互方式与逻辑
4. 容错性：预见合理误操作并防错；错误时及时反馈；支持暂停、回退、撤销或终止
5. 高效性：按使用场景提供高效、便捷的交互方式

三、壳层与导航（典型界面）
1. 标题栏
   - 高度：64px
   - 横向全屏，响应式布局
   - 背景填充色采用商飞蓝（PPT 标题：标题栏使用商飞蓝）
   - 内容：系统 Logo、系统名称、全局搜索、工具图标（帮助/通知/个人中心/国际化等）
   - 全局搜索：按需放置但鼓励提供；可搜功能名、字段、数据；需匹配个人权限
2. 导航菜单
   - 宽度约 250px，可缩进
   - 分层树形结构；图标 + 菜单名；按用户功能权限展示
3. 内容区
   - 版心与周围间距约 20px
   - 卡片/模块间距约 16px

四、颜色与视觉 Token（补充落地色）
PPT「2.5 配色 / 2.6 文字 / 2.7 圆角」以图示为主，落地建议如下：
- 标题栏商飞蓝：#0048A0
- 品牌主色（按钮/链接/选中）：#0064EF
- 页面底：#F5F7FA / #F0F2F5
- 卡片/表底：#FFFFFF；边框：#E8E8E8
- 主文字：#1F1F1F / #262626；次文字：#8C8C8C
- 成功/警告/错误：遵循 Ant Design 语义色（绿/橙/红）
- 圆角：输入框/按钮默认 4px；卡片可 4–8px
- 禁止：偏离商飞蓝主色、经营管理主站使用深色主题替代规范浅色体系

标题栏相关页高频色值（自 PPT 矢量色抽样，供对照）：
  - Slide 4: #EE822F×22, #004EA2×6, #FFFFFF×5, #C0DBD2×1, #A6CFC9×1, #7AA99E×1, #000000×1
  - Slide 5: #004EA2×6, #FFFFFF×5, #EE822F×3, #C0DBD2×1, #A6CFC9×1, #7AA99E×1, #000000×1

五、间距阶梯（PPT 2.8）
- 8px：输入框标题与输入框的左右、上下间距
- 16px：常用模块或元素距卡片底部；卡片之间上下左右间距
- 20px：页面版心与周围间距
- 28px：页面正文背景距页面底部安全距离
- 32px：界面大间距特殊场景；板块内容区与内容区划分

六、列表页（PPT 2.2）
结构：目录面包屑 → 功能名称和说明 → Tab 页签 → 工具栏/列表标题 → 表格内容 → 分页
尺寸：
- 工具按钮高度 32px，宽度随文字自适应
- 列表标题高度 55px，列宽按内容预估
- 列表行高 55px
- 分页高度跟随按钮；每页行数按需；列表区域高度宜固定，不随实际行数无序撑开
操作与展示：
- 操作列命名：查看、编辑、更多；超过 3 个低频项折叠
- 文案最多两行，超出省略号，hover 展示全部
- 状态/类型等可用标签突出层次
- 文本左对齐，数值右对齐
- 按钮超过三个：溢出到「更多」下拉
- 重要列或操作列可固定，便于快速定位
- 以纵向滚动为主，减少横向滚动；更多信息进详情
表头能力：
- 高频搜索/筛选字段可固定在表头
- 数值、日期等可表头排序
- 支持个性化表头配置与高级搜索
空状态：
- 因网络、权限、筛空、业务限制或前端渲染异常等，均需缺省页

七、表单页（PPT 2.3）
交互选型：
- 复杂度低（≤10 个字段）→ 弹窗；尺寸按内容百分比适配
- 复杂度高 → 抽屉
- 输入内容较复杂 → 新开页面
抽屉规格：
- 小抽屉：占页面 40%
- 中抽屉：占页面 60%（不含导航条）
- 大抽屉：占页面 70%（可含左侧导航条，约占抽屉 20%）
抽屉内要素：标题、表单域/分段、错误提示、填写帮助/要求；底部操作盘吸底（左下/右下按场景）；可阅读模式切换
全屏表单：底部操作盘吸底

八、详情页（PPT 2.4）
- 抽屉详情：信息左右排列，弱化列标题、强化内容；可含表格/图表/文件预览；可切换编辑模式
- 全屏详情：内容更多、需分类查看；从列表标题进入

九、按钮（PPT 2.9）
- 明确大 / 中 / 小三档（主要针对高度）
- 小：工具栏、对话框、表单行内辅助
- 中：默认；表格顶「新增/导出/高级查询」、表单「提交/取消」
- 大：登录、重要提醒等
- 按钮组类型样式统一；主次按阅读方向从主要到次要；溢出折叠始终最右
- 对齐：内容区左/右/居中按业务场景

十、输入框（PPT 2.10）
- 高度：40 / 32（默认） / 28 px
- 圆角：4px；宽度按场景
- 搜索可前置/后置；回车搜索；有字时显示清空 icon

十一、其他组件
- 单选/复选（2.11）：遵循组件库默认可用样式，保证触控热区与字号清晰
- 步骤条（2.12）：复杂或有先后关系的任务拆步；可与 icon、加载组合
- 下拉框（2.13）：与输入高度体系统一（默认 32）
- 日期时间（2.14）：以 input 唤起面板；支持单日与区间
- 标签页（2.15）：同页信息分类；当前项用主色下划线/高亮

十二、反馈提示（PPT 2.16）
1. Modal 强制弹窗警示
   - 高危不可逆：删除、清空、注销、下线等
   - 系统/数据严重异常阻断
   - 合规/权限强拦截
   - 超时/会话失效强制退出
   - 重要风险强告知（不可自动消失），如 AI 结果仅供参考
2. Message 全局轻提示：轻、短、自动消失、不阻断（成功/弱错）
3. Notification 四角通知：需知晓或可带操作（公告、异步导出、协作待办/预警等）
4. Popconfirm 气泡确认：小范围高危、就近确认、不中断整页（行内删除、重置本页筛选等）
